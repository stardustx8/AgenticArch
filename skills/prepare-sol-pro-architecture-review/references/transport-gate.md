# Pro web transport gate

Checked 2026-09-25 against [official Computer Use guidance](https://developers.openai.com/codex/computer-use/). The documented feature excludes automating ChatGPT itself. A custom harness or another browser driver is not evidence that the restriction has disappeared.

Default: prepare the exact ZIP and prompt, use manual transfer to the case's established GPT-6 Pro conversation, then verify the actual output and repository contribution. All continuation markers and private chat bindings remain durable, so a manual handoff does not lose context.

Automatic transfer may be activated only when the exact workflow has current explicit permission, an exposed supported tool, local first-send and same-chat-continuation acceptance, cancellation/recovery tests and real model identity checks. No restriction bypass, token extraction or silent API replacement. An unattended requirement remains blocked while this gate is unmet.

Export authorization binds the bundle's actual bytes, intended account/destination and scope. Login, expired authentication, security prompts and unresolvable decisions pause for the owner. Do not claim an upload from a prepared file or a model response from a stopped spinner. Keep browser profiles and private conversation URLs out of Git and model bundles.

Product limits and fallback can change. Verify the visible required Pro model for each turn; if the platform supplies another model, record the actual outcome and pause acceptance rather than suppressing safeguards or calling it Pro.

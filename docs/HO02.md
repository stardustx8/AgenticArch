# HO-02 implementation notes

## Review repair checkpoint

The focused-failure experiment now preserves the legacy suffix when all diagnostic anchors fit there. Otherwise it retains all fitting diagnostics and expands adjacent context rather than sampling twelve anchors or leaving most of the budget unused. Character caps and check exit status are unchanged. The flag remains false by default.

The opt-in Claude Stop helper accepts subdirectories under the frozen worktree root, rejects symlink escapes, checks copied executable integrity in its pinned launcher, and sets absolute `Edit(//path/**)` denies for its capsule and project `.claude` directory. `Edit` also covers Write operations; `Write(path)` is ignored by current Claude Code. CLI settings request hooks enabled while respecting managed policy precedence.

These changes do not turn file-tool rules, code hashes, or a same-user counter into an OS security boundary. Shell-level capsule mutation, check side effects in the worktree, compatibility with structured output, and actual latency savings remain unverified rollout gates. Do not enable the hook globally. Coordinator checks and completion authority remain unchanged.

The pre-HO02 runtime cases are preserved byte-for-byte in `tests/runtime_legacy.py`; the documented `tests/test_aa_runtime.py` imports them and adds the new behavioral cases. The legacy filename does not match unittest discovery, so its tests run once. The complete local suite passes 281 tests; the kit validator passes. This does not establish installed-provider behavior.

References checked 26 September 2026: [Claude permissions](https://code.claude.com/docs/en/permissions), [hooks](https://code.claude.com/docs/en/hooks), [settings precedence](https://code.claude.com/docs/en/settings). In particular, single-leading-slash file patterns are settings-relative, not absolute, and file rules do not constrain arbitrary shell subprocesses.

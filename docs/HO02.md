# HO-02: project evaluation and reviewed experiment repairs

This is an opt-in research lab, not a production rollout. Runtime defaults, subscription authentication and coordinator completion authority are unchanged. Implementation 4c3063ee374e1baf4635153dd5084b83f45180e0 passes 295 tests and the kit check locally and in [committed-source CI](https://github.com/stardustx8/AgenticArch/actions/runs/36298526422). Tests establish mechanics, not better model outcomes. The earlier 291-test receipts in RUNTIME.md and DECISIONS.md describe the preceding checkpoint.

## Corpus and coverage

`tools/ho02_projects.py` defines six synthetic existing micro-projects, each with two stages. Stage one changes a working baseline. Stage two revises the requirements on the actual delivered state, preserving still-valid behavior.

| Project | Work family and target weight | Executed formats | Contract progression |
| --- | --- | --- | --- |
| p02_export | Existing feature, 30% | Python, CSV, JSON | Round-trip CSV, then spreadsheet-safe strings without changing JSON |
| p02_delivery | Reliability, 20% | JavaScript, JSON | Acknowledge after send, then durable duplicate/conflict handling |
| p02_notes | AI/data, 15% | Python, SQLite | Latest version and verbatim/null preservation, then equal-version correction |
| p02_backup | Infrastructure, 15% | Bash, Python | Space-safe paths, then no-clobber backups and symlink rejection |
| p02_policy | Research to implementation, 10% | Python, JSON, Markdown | Resolve an approved-profile ambiguity from finite owner facts, then server delay semantics |
| p02_rank | Small change, 10% | TypeScript, JavaScript | Stable non-mutating rank, then reject non-finite inputs |

All twelve contracts pass the original importer validation: existing checks pass on base, hidden checks fail on base, and the reference passes all checks. These are executable synthetic fixtures, not six real customer repositories. Python, SQLite, Bash and JavaScript execute natively. TypeScript uses Node type stripping, not a static compiler check. Windows services, PowerShell, macOS, browser/HTML/CSS behavior, Excel and DAX/M remain unmeasured. Research uses local documents, not live web retrieval. The notes task preserves text; it does not measure ASR or model summarization quality.

```sh
python3 tools/ho02_projects.py --out /absolute/private/path/ho02-corpus
```

The destination must not exist. Materialization emits importer-compatible `import-source.json` and separate evaluator files. Workers receive only the project repo and current stage prompt; stage two never substitutes a reference solution. Hidden tests run afterwards, in separate worktrees, and are never retry feedback. Public source remains discoverable: this is not OS-enforced evaluation blindness.

## Planning, execution and recovery

Use a pinned checkout and an explicit, frozen `AA_CONFIG` before planning. Plans and resume manifests now use schema version 2 and bind effective configuration hashes as well as source, project, policy and mode. Hashes exclude per-trial state paths, not model or retry settings. CLI binary versions and server-side model changes still require separate environment receipts. Pre-v2 plans must not be relabelled as having this provenance.

```sh
python3 tools/ho02_round.py plan --name example --repeats 5 --seed 260929 \
  --mode routed --out /absolute/private/path/example.plan.json
# After reviewing the plan and imposing a host memory limit:
python3 tools/ho02_round.py execute --plan /absolute/private/path/example.plan.json \
  --out /absolute/private/path/example-runs --timeout 3600
# After inspecting an interruption, preserve the same evidence directory:
python3 tools/ho02_round.py execute --plan /absolute/private/path/example.plan.json \
  --out /absolute/private/path/example-runs --timeout 3600 --resume
python3 tools/ho02_report.py --plan /absolute/private/path/example.plan.json \
  --runs /absolute/private/path/example-runs --out /absolute/private/path/report.json
```

Planning makes zero model calls. Five repeats yield sixty project trajectories and at most 120 stage/task runs. Arms run sequentially, randomized within project/repeat pairs. `routed` uses ordinary triage; `bounded` pins only the initial tier. Neither fixes the complete solver because escalation remains possible. Separate processes, databases and repos isolate trial state; provider caches are neither disabled nor assumed equal.

The outer deadline kills ordinary descendants and stops the round. The standalone `trial` command checks time only between coordinator steps; it is not an outer process limit. Grading bounds time and retained output, not peak RSS. Impose a host memory limit for real workers. Process groups and same-user file rules are not a hostile-code sandbox. Keep arbitrary unreviewed repositories out of this synthetic lab.

Receipts are replaced atomically with fsync; attempt/call events are append-only. Explicit resume rejects changed identities before dispatch, including effective configuration drift. Completed trials do not dispatch again. Interrupted calls keep unknown cost. A corrupted/truncated journal currently fails closed and needs documented recovery; automatic repair of arbitrary power-loss damage is not implemented. A hash is provenance, not protection against a process that can rewrite both the receipt and its hash.

Three scenarios simulate a coordinator restart at a VERIFY boundary; two inject one labelled transport failure. These are not real power-loss or provider-outage measurements. The owner simulator supplies finite declared facts and cannot waive a failed spec or environment check. Authentication, quota and critical-output failures still require an operator to stop the round; a terminal BLOCKED task is a scored outcome, not by itself a global stop condition.

## Scores and review

First-result quality refers to the first submitted VERIFY snapshot, not the first partial response. Missing first submissions remain unknown with explicit coverage and lower/upper bounds. Final stage correctness requires DONE, hidden and combined checks passing, and intact protected originals. The reporter rechecks those fields rather than trusting a stored completion bit, and rejects duplicate/reordered stages and foreign trial identities.

Average final stage correctness and whole-trajectory completion are separate. Passing stage one and failing stage two yields one-half stage correctness but zero complete trajectories. A known terminated trajectory cannot claim its unattempted continuation as complete. Missing entire trajectories remain unknown. These bounds describe missing evidence, not sampling confidence intervals.

Each final snapshot includes seven 0..4 review dimensions: correctness, regression preservation, scope, maintainability, evidence, recovery and handoff. Four critical booleans remain separate: data loss, unauthorized action, fabricated verification and secret exposure. Store `review-stage-1.json` or `review-stage-2.json` in its trial directory, with concrete evidence, an identified independent reviewer and the exact final SHA.

```sh
python3 tools/ho02_round.py review --file /private/trial/review-stage-1.json --snapshot EXACT_SHA
```

The validator checks structure and snapshot identity, not independence or truth. Missing reviews mean unknown; zero observed flags with incomplete review coverage is not proof of safety. The weights are normative priorities, not a measured workload distribution. Six synthetic projects, one per family, cannot establish production noninferiority. The reporter never promotes a policy automatically.

## Review repairs, decisions and rollout

Focused failure selection preserves a sufficient old suffix; otherwise it retains all fitting diagnostic anchors and expands adjacent context. It no longer samples only twelve anchors. Tests cover multiline assertion diffs, twenty diagnostic anchors and 250 deterministic size-bound cases. These are conditional mechanical checks, not measured coding gains.

The Claude Stop launcher pins copied executable and policy bytes, accepts real worktree subdirectories, rejects symlink escapes and uses absolute `Edit(//path/**)` denies. Official [permissions](https://code.claude.com/docs/en/permissions) specify Edit rules for Write paths; `Write(path)` rules are ignored. See also [hooks](https://code.claude.com/docs/en/hooks) and [settings](https://code.claude.com/docs/en/settings), checked 27 September 2026. These rules do not constrain arbitrary same-user subprocess file access.

The Stop experiment remains off pending installed-provider checks of settings precedence, structured-output compatibility, shell mutation, check-generated artifacts and Claude-only exposure during races. Coordinator verification remains mandatory even after a successful hook, a timeout or cap exhaustion. No oracle prompt change, learned difficulty threshold, provider-loop fork or automated promotion is included.

The unchanged pre-HO02 runtime cases remain in `tests/runtime_legacy.py` and are imported once through `tests/test_aa_runtime.py`; all new behavior tests are in that entry point. Rollback means leaving the HO-01 flags false and not invoking the new lab commands. No production migration or merge is required.

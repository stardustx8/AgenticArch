Research checked on 2026-09-25. Canonical source IDs, dates, evidence classes, scoped findings and numeric comparisons are in [research-evidence.json](../config/research-evidence.json). Model routing decisions refer to these IDs rather than duplicating large source extracts in model context.

Use [MODEL-EVIDENCE.md](MODEL-EVIDENCE.md) for model interpretation, [HARNESS-DECISION.md](archive/HARNESS-DECISION.md) for harness selection and [SUBSCRIPTION-EVALUATION.md](SUBSCRIPTION-EVALUATION.md) for local measurements. Source claims are not implementation receipts or account permissions. Current provider rules need rechecking when interfaces change.

The evidence set includes the original HarnessTax study, official model/product/effort/authentication guidance, the CLM and Pi source interfaces, Astra-Ares architecture, an independent evaluator, and two authored firsthand comparisons. Social reposts, vendor-hosted testimonials and anticipatory release claims are not treated as independent measurements. The accessible editorial text was reviewed; no unseen video transcript is claimed to have been reviewed.

No controlled comparison yet establishes a universally optimal model/effort/harness combination for this owner's workload. New benchmark results must retain exact versions, effort, fallback behavior, repetitions, task denominators and uncertainty. Do not merge different benchmark versions or convert an API rate card into observed subscription consumption.

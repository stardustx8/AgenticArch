The integrated files arrived as ordered format-patches in `HO03-recovery-314-complete.zip` because the worker-file write was blocked; they are now published on this branch (see [HO03-DELIVERY.md](HO03-DELIVERY.md)), so these commands run from it. ## Projects and interpretation

`python3 -m tools.ho03_projects --validate --out /absolute/new/private/fixture-export` exports the six synthetic existing projects and their twelve stage contracts. Check every returned `valid` value; use the private `validate_recovery.py` for an asserting, zero-worker preflight. Hidden/reference files are evaluator-only. Never give the fixture export to a worker.

The three middle probes cover source-grounded notes, transactional incremental imports, and a previously exposed policy bridge. The three ultra projects cover durable tenant jobs and JavaScript reconnection; bitemporal reporting and atomic imports; and safe transactional restore and recovery. Ultra labels are author predictions, not established model difficulty. Native calibration decides whether the labels are useful. Local SQLite, file operations and JavaScript reducers execute for real; remote services, browser behavior and abrupt hardware power loss are not validated here.

## Runtime contracts

`harness_opt.codex_no_memories` is false by default. Enabling it adds three native per-call Codex settings: `features.memories=false`, `memories.use_memories=false`, and `memories.generate_memories=false`. No credential is copied or moved. These controls concern automatic memory injection/generation, not filesystem read isolation. The installed CLI must pass a private trace inspection before a native round; settings accepted on the command line alone do not establish exclusion.

The primary comparison uses `mode=bounded`, `comparison_tier=medium_tough`. Minimal uses Astra high and coordinator checks, not the historical Luna minimal baseline. Full adds its existing race/oracle/spec machinery; this is a whole-pipeline comparison, not attribution to an individual gate. Original triage information is retained. Tough escalation creates a private, hash-bound `AWAITING_PRO` handoff with completion false, not a missing-origin transport failure or a fictitious completed response. The separate routing phase dispatches triage only and never a local coding worker.

Per-trajectory and per-round deadlines persist across resume and include downtime. A changed budget or inconsistent clock record fails rather than refreshing the allowance. Completed result files prevent repeated dispatch. An interrupted model call is retained with unknown usage. Process groups are useful cleanup, not complete containment of provider processes that start their own sessions. Run the whole experiment in the operator-verified systemd cgroup with a memory limit and control-group cleanup.

Stage-start protected hashes distinguish a new violation from damage inherited from stage one. Whole-trajectory correctness still requires original protected work to be preserved. Restoration of original bytes is not a new violation. Hidden grading is deferred until all model work in that trajectory has ended. This removes its own stage-one grade directory from stage-two context, but does not isolate other trials or the public reference source. Those remain explicit leakage-audit gates.

A missing tier is an unresolved handback, never permission to confirm unrelated checks. Copied Stop-hook hash failures produce an audit event and retain coordinator verification. Native hook precedence, shell-level tampering and generated artifacts are not resolved merely by a hash or a file-tool deny.

## Plan, execute, inspect

`tools/ho03_round.py plan --name NAME --phase PHASE --seed 261001 --out PLAN.json` makes a source/configuration/catalog-bound plan. Plan generation and reporting call no models. `native-template --out AUDIT.json` records installed versions and leaves approval fields empty. Supply real evidence rather than changing empty fields to true without inspection.

`execute --plan PLAN.json --out PRIVATE_RUN_DIR --native-audit AUDIT.json` is the native entry point. Use `--resume` only for that same directory and plan. `trial` is an internal subprocess entry, not a way to bypass preflight. Reporting uses `report --plan PLAN.json --runs PRIVATE_RUN_DIR --out REPORT.json`.

Middle trajectories have 600-second caps; ultra trajectories 1,200 seconds; routing probes 600 seconds. These are caps, not forecasts. Deadline and resource failures must not be discarded as cheap failures.

Calibration's first pair is a privacy/evidence/critical-failure check. After six trajectories, pooled middle stage correctness must be in [0.20, 0.80], at least one middle project must be mixed, and at least one middle trajectory must fully succeed. A pass average made only from solved and unsolved projects is not adequate evidence of an intermediate band. The final ultra block may be at the floor, but a pooled pass rate over 0.85 refutes its current hardness prediction. These thresholds are screening rules, not significance tests.

Each pause writes `checkpoint-N.json`. `audit-N.json` must bind its digest and name an operator and inspected evidence, with explicit true findings for no personal memory, no evaluator access, no artifact failures, no critical failures, and sufficient trace coverage. Any recorded critical/protected failure stops regardless of an optimistic audit. `PAUSED_FINAL_AUDIT` is not permission to promote defaults.

Extension additionally requires `--calibration CALIBRATION_DIR` and the accepted full primary calibration. Upper-only diagnostic additionally requires that linked primary calibration stopped only for discrimination after its first six trajectories, no ultra work was attempted, and a signed-by-name `upper-only-authorization.json` binding the failed checkpoint. It replaces the still-unrun upper block; it cannot unlock extension or bypass a privacy, resource or evidence failure.

## Scores and handoff

Report first snapshot coverage, final stage correctness, whole-project correctness, stage-local delta correctness, new protected violations and tainted stages separately. Missing submissions stay unknown. Handoff hash completeness is not semantic sufficiency, accepted transport or solved work. Apply the existing seven-dimension, four-critical-category rubric to exact snapshots with independent evidence. Tests pass/fail cannot replace a review of scope, maintainability or fabricated verification. Vendor token fields are proxies, not measured subscription currency.

The private SCORING.md and EXPERIMENTS.md define the frozen estimands, operator review fields, source-application instructions and native commands. A six-project diagnostic, including an exposed bridge, cannot establish a production routing boundary or the owner's two-percentage-point noninferiority margin.
